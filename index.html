How it works

A lesson you do, not a page you finish.

CDI’s own workflow keeps four things: the input table, the script, the cleaned output, and the report. The report is the part that makes the other three trustworthy — so the lessons are built around producing one.

cleaning-report.txt · excerpt

  1. MEASURED150 rows, 5 columns, 0 missing values
  2. RULE APPLIEDColumn names standardized to snake_case
  3. DECISION5 identical rows retained — no unique identifier
  4. VALIDATEDSchema, dtypes and completeness all passed
  1. 01

    Decide, don't just read

    Every section asks you to make a call before it tells you the answer. Reading about a decision is not the same as making one.

  2. 02

    Every decision is logged

    As you work, a plain-language record builds beside the lesson: what you measured, what rule you applied, and why.

  3. 03

    You leave with an artifact

    The record becomes a cleaning report — the same file the reusable script produces. It is evidence, not a completion badge.

  4. 04

    Go deeper when you want to

    Each section links to the full chapter it came from. The lesson is a front door to 132 chapters, not a replacement for them.
